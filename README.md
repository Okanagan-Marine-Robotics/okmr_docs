# okmr_docs

A shared [Obsidian](https://obsidian.md/) vault meant to keep club knowledge accessible by all members of OKMR.

## How to install

1. Download [Obsidian](https://obsidian.md/)
2. Download the repository
	- Either `git clone https://github.com/Okanagan-Marine-Robotics/okmr_docs.git
	- Or download and extract the repo
3. Open the `okmr_docs` folder in Obsidian.
4. Explore!
